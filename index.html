Homework 8: Final Project Data and EDA¶

Project statement

Electric Vehicle Adoption Across Washington State

  • How does Electric Vehicle (EV) adoption differ across Washington counties, and what patterns do we see?

Data Sources:

We chose three official datasets from the repositories:

  • 1. EV Population Size History by County :
    • Each row contains counts for a county, month, and vehicle-use category
    • Link to dataset: Washington Open Data
  • 2. Electric Vehicle Population Data:
    • Each row contains one registered EV, with county, type, make, and model
    • Link to dataset: Washington Open Data
  • 3. Median Household Income, 2024 (SAIPE):
    • Each row contains one county's estimated median household income
    • Link to dataset: U.S. Census Bureau

We used 2024 EV data for the income comparison because the Census income estimates are for 2024.

monthly_charts = []

for i, month in enumerate(month_order):
    data = income_ev_2024[income_ev_2024['month'] == month]
    base = alt.Chart(data)

    # Show shared axis titles only on the bottom row and left column.
    x_title = '2024 median income ($)' if i >= 8 else None
    y_title = 'Passenger EV share (%)' if i % 4 == 0 else None

    points = base.mark_circle(size = 45, opacity = 0.75).encode(
        x = alt.X('median_income:Q',
            title = x_title,
            axis = alt.Axis(format = '$,.0f', tickCount = 4)
        ),
        y = alt.Y('ev_pct:Q',
            title = y_title,
            scale = alt.Scale(zero = True)
        )
    )

    trendline = base.transform_regression(
        'median_income', 'ev_pct'
    ).mark_line(color = 'red', strokeWidth = 2).encode(
        x = 'median_income:Q',
        y = 'ev_pct:Q'
    )

    monthly_charts.append(
        alt.layer(points, trendline).properties(
            title = month, width = 250, height = 160
        )
    )

# Arrange the charts in rows of four.
chart_rows = [
    alt.hconcat(*monthly_charts[i:i + 4])
    for i in range(0, len(monthly_charts), 4)
]

income_grid = (
    alt.vconcat(*chart_rows)
    .resolve_scale(x = 'shared', y = 'shared')
    .properties(title = 'County Income and Monthly EV Share, 2024')
)
